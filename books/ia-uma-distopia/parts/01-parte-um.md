[[?autor: o texto de abertura da Parte I. Um ou dois parágrafos que dizem o que
esta parte faz, escritos depois que os capítulos dela existirem — uma abertura
de parte escrita antes descreve a parte que foi planejada.]]

Este arquivo é um andaime: existe para o livro compilar e para mostrar onde a
abertura de parte mora. O campo `part:` acima é o que casa esta abertura com os
capítulos — eles carregam a mesma string no `part:` deles.
